# Publication CampusRide — 11 novembre 2026

Les corrections fonctionnelles du 4 novembre ont été comparées aux fonctions réelles puis appliquées à Supabase. L’écart de la fonction API avant application était une indentation seulement. Les tables, comptes et données métier existants sont préservés, vérifiés par empreintes des anciennes lignes.

Le nouveau jeu fictif couvre les jours de semaine du 11 novembre au 20 décembre 2026 : trois comptes marqués Démo, 59 trajets, 11 réservations et quatre avis sur les trajets terminés du matin du 11 novembre. Le dernier trajet est le vendredi 18 décembre, le 20 étant un dimanche. Benjamin et Patrick sont conservés. Les nouveaux comptes utilisent le même mot de passe de test existant, sans secret écrit dans le dépôt.

Comptes : Démo — Alice Martin ; Démo — Karim Benali ; Démo — Léa Dubois. Chacun conduit majoritairement et réserve occasionnellement. Les répétitions sont des trajets et réservations concrets de démonstration ; aucun moteur de récurrence automatique n’est ajouté.

L’import est transactionnel et idempotent via une table privée de correspondance. Tests locaux PostgreSQL 17 : deuxième passage sans doublon, données préexistantes inchangées, rejet atomique sans entrée de hash, capacités/dates/avis/droits valides. Frontend : compilation et huit recherches ordonnées + douze scénarios React réussis.

## Limite de mise en page

Le widget CUSTOM_WIDGET classique Free propose Fixed ou Auto Height, sans Fit page. La largeur responsive et le scroll de page unique restent utilisés. Les barres et le champ de message suivent le contenu ; leur fixation au viewport extérieur reste non résolue. Aucun abonnement n’a été modifié.
